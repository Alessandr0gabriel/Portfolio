# Portfólio — Alessandro Gabriel

Portfólio pessoal de Alessandro Gabriel Jandoza Grella, estudante de Engenharia de Software na UNINGÁ e desenvolvedor Full Stack em formação. O site apresenta projetos pessoais e acadêmicos, tecnologias estudadas e canais de contato para oportunidades de estágio.

## Executar localmente

Abra `index.html` em um navegador ou use a extensão Live Server no VS Code. O projeto é estático e não requer instalação de dependências.

## Estrutura

- `index.html` — conteúdo semântico, metadados e estrutura das seções.
- `style.css` — identidade visual, layout responsivo e estados de foco.
- `script.js` — menu mobile, ano do rodapé e botão de retorno ao topo.
- `gallery/` — retrato e imagens otimizadas dos projetos.

## Projetos apresentados

- **Vendly Commerce:** aplicação de gestão comercial. O repositório público documenta pedidos, estoque, dashboard, faturamento, autenticação, isolamento de dados, integração de pagamentos e eventos em tempo real. A captura usada no portfólio é do ambiente de desenvolvimento e contém dados demonstrativos.
- **Lar São José:** projeto acadêmico de site institucional e divulgação da ACPIC Lar São José. O link leva ao repositório público; a demonstração hospedada não está incluída porque o endereço publicado não respondeu.

Os projetos são apresentados conforme o material público consultado. Não há demonstração online do Vendly indicada neste portfólio.

## Publicação

O site pode ser publicado como conteúdo estático, por exemplo, com GitHub Pages. Configure a publicação para servir `index.html` a partir da raiz do repositório e confira a URL gerada antes de divulgá-la. O endereço público não está configurado neste projeto.
